# Discovering-immune-sub-groups-in-pre-eclampsia-data
## Discovering immune sub groups in pre eclampsia data through unsupervised learning techniques
This project investigates immune system patterns associated with preeclampsia using high-dimensional single-cell mass cytometry (CyTOF) data. The goal was to develop a robust unsupervised learning framework capable of identifying hidden immunological subtypes during pregnancy and revealing early immune dysregulation associated with preeclampsia.

The study analysed peripheral blood mononuclear cell (PBMC) samples from 45 pregnant women, including both healthy controls and preeclampsia cases, using a dataset containing 33 immune markers per cell. After preprocessing and normalization using an arcsinh transformation, dimensionality reduction techniques were applied to manage the high-dimensional structure of the data. Two analytical pipelines were evaluated: clustering directly in PCA space and clustering within UMAP-embedded spaces. Three clustering algorithms were implemented and compared—K-means clustering, HDBSCAN, and PhenoGraph—to discover immune cell subpopulations across different gestational stages.

Clustering quality and robustness were assessed using several evaluation metrics, including Silhouette score, Davies–Bouldin index, and Calinski–Harabasz index, along with composite scoring and cross-algorithm validation through the Adjusted Rand Index and Adjusted Mutual Information. The results showed that UMAP-based clustering consistently outperformed PCA-only approaches by producing more compact and well-separated clusters.

Among the algorithms, K-means and HDBSCAN demonstrated the strongest clustering performance, while PhenoGraph captured more granular immune microstructures. Marker enrichment analysis and weighted cell-type scoring were then used to interpret cluster identities and identify biologically meaningful immune populations. The analysis revealed early and persistent enrichment of myeloid, cytotoxic, and dendritic immune cell populations in preeclampsia samples beginning from the first trimester, indicating early immune dysregulation.

Overall, this project demonstrates how combining dimensionality reduction and multiple unsupervised clustering algorithms can reveal complex immune patterns in high-dimensional biomedical data. The framework provides a computational approach for discovering early immunological signatures associated with preeclampsia and highlights the value of unsupervised machine learning in biomedical discovery.
